GOOGLE SPREADSHEET

Sinkronisasi Data

Koneksi Google Apps Script sudah tertanam pada aplikasi dan berlaku otomatis untuk semua perangkat.

Mode Lokal

Data tersimpan di browser perangkat ini.

Penting:Tidak ada login. Pemulihan akan langsung mengirim data browser ini ke Spreadsheet.
PETUNJUK UPDATE

Setelah Mengganti Code.gs

  1. Ganti seluruh kode Apps Script dengan Code.gs v3.2 tanpa login.
  2. Pastikan SPREADSHEET_ID benar.
  3. Jalankan setupSheets() satu kali setelah update Code.gs.
  4. Buka Deploy → Manage deployments.
  5. Edit deployment, pilih New version, lalu Deploy.
  6. Gunakan URL yang tetap berakhiran /exec.
Mode tanpa login: aplikasi langsung terbuka. Semua pengguna yang memiliki alamat web dapat mengelola data.
